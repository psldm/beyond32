# beyond32 — superconducting pairing channels of the icosahedral group

Companion code of

> Eva Moss, *Beyond the 32: Superconducting Pairing Channels of the Icosahedral Group —
> Classification, Approximant Branching, and Ginzburg–Landau Theory for Quasicrystals* (2026).

Every table and every displayed equation of the paper is regenerated by one command, in exact
arithmetic where the paper is exact and with fixed random seeds where it is numerical.

## What the code computes

The icosahedral group `I` (order 60), its full point group `I_h = I × {E, i}` and its double
group `2I` (120 unit quaternions) are constructed explicitly over the number field Q(√5), and
from them:

| paper | content | module / function |
|---|---|---|
| Table 1 | character table of `I` (classes E, 12 C5, 12 C5², 20 C3, 15 C2) | `groups.CHAR_I` |
| Table 2 | character table of `2I` (classes by SU(2) angle 0, 72, …, 360°) | `groups.character_table_2I()` |
| Eq. (1) | orientation: two-fold axes x, y, z; three-fold (1,1,1); five-fold (±φ, ±1, 0) + cyclic | `groups.fivefold_axes()` … |
| Table 3, Eq. (3) | branching SO(3) ↓ I of the spherical harmonics, ℓ ≤ 6 (projectors and characters) | `harmonics.branching(l)`, `harmonics.branching_by_characters(l)` |
| Eqs. (4)–(9) | basis functions in φ-form from symmetric seeds | `harmonics.paper_basis_functions()` |
| Eqs. (10)–(11) | the ℓ = 6 invariant P6 and the hexad identity | `harmonics.invariant_P6()`, `harmonics.hexad_identity()` |
| Table 4 | permutation representations of `I` and `I_h` on the 12-, 20-, 30-, 60-orbits | `shells.shells_table()` |
| Eqs. (12)–(13) | SU(2) → 2I branching, antisymmetric/symmetric pair decompositions | `double_group.su2_branching()`, `double_group.pair_decomposition()` |
| Eqs. (15)–(16) | Molien series, m_A(ℓ) for ℓ ≤ 30, spectrum of the Poincaré space S³/2I | `molien.m_A_table()`, `molien.poincare_spectrum()` |
| Table 5 | restrictions to T, D5, D3 (characters) and D2 (parities of the basis functions) | `restrictions.restriction_table()` |
| Section 7 | Γ ↓ C_n: G ↓ C5 has no trivial character (enforced nodes) | `restrictions.restrict_to_cyclic()` |
| Table 6, Eq. (17) | Sym²Γ, number of Hermitian forms and of quartic terms | `gl.sym2_table()` |
| Eqs. (18)–(21) | N_L in terms of I1, I2 (and N2 for G); the H intertwiner J and cross terms | `gl.relations()`, `gl.h_channel()` |
| Eq. (22) | weak-coupling ∫\|Δ\|⁴ per channel | `gl.relations(name)["quartic"]` |
| Eq. (23) | G ground state (κ, φ₀, R = 1.52545), best null-cone state 1.52721 | `gl.g_stratum()`, `gl.g_ground_state()` |
| Section 6.3 | 18 point nodes of the G ground state, 12 on the five-fold axes | `gl.g_nodes()` |
| Table 7 | symmetry-fixed states (K, χ), R_wc, time reversal, min\|Δ\| | `gl.symmetry_fixed_states()` |
| Table 8 | anisotropic invariants of the null-cone H states | `gl.h_candidates()` |
| Appendix B, Eq. (24) | dodecagonal group D12: irreps, m mod 12, enforced nodes, Sym² E_m, circle ratios | `d12.summary()` |

## Install

Python ≥ 3.10 with `sympy`, `numpy`, `scipy` (and `pytest` for the tests):

```bash
git clone https://github.com/psldm/beyond32
cd beyond32
python -m venv .venv && source .venv/bin/activate
pip install -e ".[test]"
```

## One-command reproduction

```bash
beyond32 all          # writes results.json and tables/*.tex (about half a minute on a laptop)
beyond32 check        # recomputes the key numbers and compares them with the paper
beyond32 gl           # Ginzburg-Landau summary on the terminal
beyond32 tables       # LaTeX fragments from an existing results.json
pytest                # every number quoted in the paper, pinned literally (~1 min)
pytest -m "not slow"  # without the slow cross-checks
```

`beyond32 all --fast` skips the optional slow cross-checks (the ℓ = 5, 6 isotypic bases, the
Sym² projector ranks, the Molien closed form derived from the 60 matrices). `--cache` keeps a
copy of `results.json` under `.cache/` (git-ignored), which `beyond32 tables` will reuse.

`tables/` contains one fragment per table of the paper, named after the paper's labels:
`tab_charI`, `tab_char2I`, `tab_branching`, `tab_shells`, `tab_restrict`, `tab_GL`,
`tab_states`, `tab_Hcand`, `tab_D12`, plus `tab_molien` (Eqs. 15–16), `tab_double_group`
(Eqs. 12–13), `eq_bases` (Eqs. 4–11) and `eq_invariants` (Eqs. 18–23). The fragments are
`tabular`/`align*` environments meant to be `\input` into a float; they are committed so
that readers can diff them against the paper. `results.json` holds the same numbers in
machine-readable form.

## Conventions

* **Orientation of the icosahedron** (Eq. 1 of the paper): two-fold axes along x, y, z;
  three-fold axes along (±1, ±1, ±1); the six five-fold axes along the cyclic permutations of
  (±φ, ±1, 0), φ = (1+√5)/2. The tetrahedral subgroup T is generated by the coordinate two-fold
  rotations and the cyclic permutation x → y → z → x; the D2 labels B1, B2, B3 are the
  representations invariant under the two-fold rotations about z, y, x.
* **Classes of I**: E, C5, C5², C3, C2 (sizes 1, 12, 12, 20, 15), identified by the rotation
  angle. **Classes of 2I**: labelled by the SU(2) angle α = 0, 72, 120, 144, 180, 216, 240, 288,
  360° (the element −1 is α = 360°), sizes 1, 12, 20, 12, 30, 12, 20, 12, 1. **Improper classes
  of I_h** are listed as −R for R in E, C5, C5², C3, C2 (Schoenflies i, S10³, S10, S6, σ).
* **Irreps**: A, T1, T2, G, H for I (T1 has character φ on C5); A_g/A_u etc. for I_h; the spinor
  irreps of 2I are 2, 2′, 4_s, 6 (character −dim on −1); 2 ⊗ 2′ = G.
* **Basis functions**: the orthonormal (sphere inner product ∫dΩ/4π) bases used for the irrep
  matrices are T1: x, y, z; H: xy, yz, zx, (x²−y²)/2, (2z²−x²−y²)/(2√3); T2: f_x, f_y, f_z;
  G: g_x, g_y, g_z, xyz (Eqs. 4–7). The order parameter η is expanded in these bases:
  Δ(n̂) = Σ η_i b̂_i(n̂), so that ∫|Δ|² dΩ/4π = |η|².
* **Invariants**: I1 = (η·η*)², I2 = |η·η|², N_L = ∫|[Δ²]_L|² dΩ/4π. The H intertwiner J is
  built by Schur averaging of a fixed generic seed (`random.seed(3)`, as in the original
  scripts); Table 8 quotes Re C with J normalised to an isometry, so the seed does not matter
  there.
* **Numerics**: BFGS with 60 random restarts (`numpy` seed 0) per channel and 80 (seed 1) for
  the G ground state; node search on a 1200 × 2400 θ–φ grid; isotropy fixed spaces by SVD.
  Everything else is exact.

## Layout

```
beyond32/groups.py        2I, I, I_h; classes; character tables; axes
beyond32/harmonics.py     action on polynomials, projectors, branching, basis functions, P6
beyond32/molien.py        m_A(l), Molien series, S^3/2I spectrum
beyond32/restrictions.py  I -> T, D5, D3, D2, C_n
beyond32/shells.py        permutation representations on the orbit shells
beyond32/double_group.py  SU(2) -> 2I, pair decompositions
beyond32/gl.py            Ginzburg-Landau theory (exact forms + numerical minima)
beyond32/d12.py           the dodecagonal group D12
beyond32/latex.py         LaTeX fragments;  beyond32/results.py  results.json;  beyond32/cli.py
beyond32/_exact.py        the field Q(sqrt5) (sympy) and DomainMatrix helpers
tests/                    one test module per package module; reference values pinned literally
```
